Part A · calculate a step response

Run Step response twice and export each run before Reset. Use the full-run graph and point readings to record xinitial, xfinal, xpeak, corresponding peak times, rise time, and settling behaviour. State your rise-time and settling-band definitions.

PO = 100 |xpeak − xfinal| / |xfinal − xinitial|
ζ₁ = −ln(PO/100) / √[π² + ln²(PO/100)]
Td = tnext peak − tpeak; ωd1 = 2π/Td; ωn1 = ωd1/√(1 − ζ₁²)

Use these identification formulas only for a valid underdamped prototype step from rest. Without overshoot, omit ζ₁ from PO; without successive peaks, omit ωn1 from a peak period. With zero damping there is no settled final value: label F₀/(k₁+k₂) as the theoretical equilibrium instead.

Case C · connect the derivation to the simulation
m·ẍ + (c₀+cₘ)·ẋ + (k₀+kₘ)x = kₘyₘ + cₘẏₘ
yₘ = Yₘ sin(ωt); ẏₘ = ωYₘ cos(ωt)

In Case C mode, the left spring control is kₘ, the right spring is k₀, and c is c₀. Assume xp = a sin(ωt) + b cos(ωt), differentiate, and match the sine and cosine coefficients to derive the two equations in Section 5 of the manual.

X/Yₘ = √[kₘ² + (cₘω)²] / √[(k₀+kₘ−mω²)² + ((c₀+cₘ)ω)²]
φ = atan2(cₘω,kₘ) − atan2((c₀+cₘ)ω,k₀+kₘ−mω²)

Compare the derivation with your sampled Case C sweep. The orange plot is the equivalent force; its phase differs from yₘ when cₘ ≠ 0. The dashed yₘ trace and sweep phase use motor displacement as the reference.

Reading a step response

The three steps below assume dry friction is off. Read the input and the cart motion together: the force jumps, but the cart takes time to respond. Click a graph to compare quantities at the same instant.

1 · Find when the force turns on

Before the step time ts, the force is zero. At ts, it switches to F₀ and stays there.

F(t) = 0 before ts
F(t) = F₀ from ts onward

Look for the vertical marker and the jump in the orange force trace. Displacement and velocity stay continuous; acceleration changes immediately by F₀/m.

2 · Predict the final position

Both springs oppose cart motion, so their stiffnesses add. At rest, the springs balance the applied force.

xstatic = F₀k₁ + k₂

Step preset example: 4 N ÷ 80 N/m = 0.050 m = 50 mm. The dashed line shows this equilibrium.

With damping, motion settles here. With zero damping, the cart keeps oscillating about it.

3 · Compare the peak and settling

For a nonzero step starting from rest at x = 0:

0 ≤ ζ < 1: the response overshoots. More damping reduces the overshoot; ζ = 0 never settles.

ζ = 1: critical damping, with no overshoot.

ζ > 1: overdamping, with no overshoot and a slower approach than critical damping at the same mass and stiffness.

Nonzero initial displacement or velocity adds a free response and can change the peak.

Dry friction and sticking

Dry friction acts in addition to viscous damping. While sliding, its force is −Fc sign(v). At rest it balances the residual drive F − kx, up to ±Fc; motion starts only when that limit is exceeded. Static and sliding friction use the same adjustable force limit in this idealized model.

A small step can leave the cart stuck. Free oscillations can stop at a nonzero displacement, and a sinusoidal input can produce stick–slip motion. These are illustrative effects, not calibrated OSCAR friction measurements. The frictionless equilibrium line and linear reference equations do not predict the full frictional response. Use friction off for the standard identification and frequency-sweep calculations.

Equations and modelling assumptions
m·ẍ + c·ẋ + (k₁ + k₂)x = F(t)

x is measured from the unforced equilibrium. In step mode both anchors stay fixed. Free vibration uses F = 0. Original moving-anchor mode uses yₘ = A sin(ωt) and F = k₁yₘ. Direct-force mode uses F = Fₐ sin(ωt). Case C adds coupling damping: F = kₘyₘ + cₘẏₘ and total damping c₀+cₘ. A is converted from mm to m.

ωₙ = √[(k₁ + k₂)/m]
ζ = c / [2√(m(k₁ + k₂))]

For a nonzero step from zero initial displacement and velocity, the percentage overshoot is:

Overshoot (%) = 100 exp[−πζ / √(1 − ζ²)]
Applies for 0 ≤ ζ < 1; zero overshoot for ζ ≥ 1 under these initial conditions.

Step mode disables contacts and cart dragging to preserve the linear equation. Its picture is limited to ±250 mm, while graphs and selected points retain the full calculated motion. Free and sinusoidal modes retain the original bump stops and dragging.

Reset, timing, and graph controls

Reset & pause clears the recorder, sets time and motor phase to zero, and reloads x₀ and v₀. Play resumes; Pause freezes the clock and input. A step with ts = 0 is already on at Reset.

Changing mode or step force/onset resets and pauses. Other parameter sliders change the model immediately and start a new logged setup segment, so reset between comparisons and export before Reset. Presets reset and start their runs. Step force stays constant after onset until settings or mode change.

Click or tap a compact graph to expand it, pause, and select the nearest recorded time. Expand graphs opens a larger live view; its Play/Pause button controls the run. The vertical cursor and coloured dots link the three lanes; numerical values appear below. ← and → move one recorded point, Home/End jump to the first/latest point, and Escape closes the expanded view (or clears the selection in the compact view). Clear selection leaves the run paused; Play clears it and resumes.

Each lane has its own units and scale. The default view shows the last 10 simulation seconds. Choose a shorter window for high-frequency point readings or Full run to revisit the initial response. All samples from the current run are retained for CSV export; Reset begins a new run. Use Close expanded view to return the graphs beside the cart. At step onset, two samples show the values immediately before and after the switch; use the arrow keys to inspect both.
